# Requirements and traceability

## Course guidelines (from the instructor)

> Choose a publicly available dataset and apply optimisation techniques from the course. Create a user interface through which
> the data can be loaded, some statistics about the data can be generated on demand, and at least two optimisations can be done
> (chosen by the user). Any tool may be used.

| Guideline | Requirement | Where it is met |
|---|---|---|
| Public dataset | Official NRP benchmark instance(s) | `data/raw/Instance3.xml` (main), Instances 1, 2, 4 as extra samples; provenance in `data/raw/README.md` |
| Data can be loaded | Upload or select a dataset in the UI; parse automatically | Dataset page; `src/parser.py`; diagnostics for unsupported features |
| Statistics on demand | User chooses and generates statistics | Statistics page (5 selectable groups, 10 charts, tables, CSV) - `src/data_statistics.py`, `src/stat_charts.py` |
| >= 2 optimisations, user-chosen | Integer Programming and Goal Programming, run from the UI | Optimization page (separate *Run* buttons, time limits, GP weights) |
| Course techniques | Integer programming; goal programming | `src/integer_program.py`, `src/goal_program.py`; Model page |

## Non-functional requirements

| Requirement | How it is ensured |
|---|---|
| Academically rigorous, defensible in a viva | Formulations written out (`docs/MATHEMATICAL_MODEL.md`, Model page); `docs/VIVA_GUIDE.md` |
| Dataset fidelity - no invented fields, constraints or requests | Only XML data is used; unsupported XML features are reported as warnings |
| No fabricated numbers; optimality not assumed | Honest solver status; every objective recomputed independently; results generated by scripts; saved solutions re-verified on load |
| Technology: Python, Pandas, NumPy, PuLP, Streamlit, Plotly; no machine learning | `requirements.txt`; no ML anywhere |
| Distinct models | IP = benchmark-faithful; GP = explicit goals with deviation variables; formulations pinned by `tests/test_model_unchanged.py` |
| Reproducibility | `scripts/`, `run_tests.bat`, `requirements.txt`, `run_app.bat` |
