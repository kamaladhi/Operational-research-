# Testing

```
run_tests.bat            # fast suite, about 1 minute (114 tests run, 3 slow ones skipped)
run_tests.bat slow       # everything, about 6 minutes (adds live solves of Instances 3 and 4)
python -m unittest discover -s tests -t .          # same, without the batch file
```

**117 tests, all passing** (verified in a fresh virtual environment built from `requirements.txt`).

| File | What it proves |
|---|---|
| `test_model_unchanged.py` | **The two formulations are exactly as originally delivered**: variable inventory and a structural hash (names, bounds, every constraint, objective) pinned from the original code |
| `test_live_solvers.py` | Both models run end-to-end: IP reaches the published optimum on Instances 1-4 (3 and 4 under `slow`), GP is optimal with the regression values; every roster validated; objectives recomputed independently |
| `test_solver_status.py` | "Optimal" only when CBC proved it; a 5-second run on Instance 3 comes back "Feasible", not proven |
| `test_evaluation.py` | The independent evaluator reproduces solver objectives exactly (IP, and GP for w4 in {0, 0.2, 0.5, 1}); the validator rejects a broken roster |
| `test_reference_solutions.py` | Saved solutions: proven optimal, equal to published values, **tamper-evident** (changed objective, broken roster, wrong instance are all rejected) |
| `test_parser.py` | Dimensions and values of Instances 1-4; compatibility warnings for unsupported XML; invalid files rejected |
| `test_benchmarks.py` | Instance identification by fingerprint, published values, no benchmark for a modified dataset, gap formula |
| `test_statistics.py` | Tables, statistics and all 10 charts, with exact numbers (154 required nurse-shifts, 155 maximum capacity, 64 requests, ...) |
| `test_comparison.py` | Comparison metrics, computed (not assumed) validation, gap handling for known / unknown instances, JSON export |
| `test_reporting.py`, `test_visualization.py` | Result tables add up (shift-wise = day-wise = coverage summary); charts show the right content |
| `test_app.py` | Every page of the Streamlit app, driven headlessly: cold start, loading a sample, every statistics panel, loading and running solutions, all result pages, failure path (no solution), GP-weight warning, reset |

## Beyond the automated suite

* **Model equivalence**: the LP files generated by the original and the final code are byte-identical for both models.
* **Real browser**: the running app was driven in Microsoft Edge (Playwright) through the full demo path with no page errors.
* **Visual check** of the charts in a browser.
* **Generalisation**: the unchanged IP also reached the published optimum on Instance 4 and valid near-optimal solutions on
  Instances 5 and 6.

## Design notes

* Page-rendering tests use the saved reference solutions (loaded through the same buttons a user clicks), so they are fast and
  deterministic; one end-to-end test clicks the real *Run* buttons on Instance 1.
* `RUN_SLOW_TESTS=1` enables the minutes-long Instance 3 / 4 solves.
